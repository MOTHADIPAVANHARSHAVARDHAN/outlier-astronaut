THE OUTLIER ASTRONAUT

Mission Briefing: You pilot a spaceship navigating a cosmic debris field with noisy sensor data.

Controls: Slide the Z-Score threshold. Use UP / DOWN arrow keys or drag the spaceship manually to dodge hazards.

Data Science Rules:

  • False Positive (Z too low): Ship dodges harmless background noise, wasting fuel.
  • False Negative (Z too high): Ship ignores asteroids, taking severe hull damage.
  • Sweet Spot: Set Z between 2.0 and 3.0 using the empirical rule ($\mu \pm 2\sigma$).

HOLOGRAPHIC CONSOLE

Pandas Backend Formulas:
Rolling Mean ($\mu$) = $\frac{1}{n}\sum x_i$
Std Deviation ($\sigma$) = $\sqrt{\frac{\sum(x_i - \mu)^2}{n-1}}$
Z-Score ($Z$) = $\frac{x_i - \mu}{\sigma}$

1.0 (Under-filter / Danger) 4.0 (Over-filter / Fuel Drain)
